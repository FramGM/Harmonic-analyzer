Графическое представление гармоник.\
Есть Авто-масштабирование.\
График можно просматривать зажав ЛКМ.\
График можно настраивать дополнительно с помощью ПКМ.\
Также нажав на одну из легенд, можно убрать из отображения на графике.\
\
Есть отображение всех, четных, нечетных гармоник.\
Есть отображение максимальной высоты.\
Есть отображение линии максимумов.\
Есть сброс параметров.\
\
Управление:\
Нажатие на слайдер, затем нажатие Tab на нем позволяет поставить значение с точностью до 3-ех знаков
